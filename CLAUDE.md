# Fianna Fit

Low-friction workout logger. Project plan, phases and issues live in Linear (project "Fianna Fit", team DAI).

## Workflow rules
- Never run `git commit` or `git push` unless the user explicitly says to in that message. Permission to commit once does not carry over to later changes.
- The user reviews all generated code and tests it manually as the acceptance gate. After making changes, stop and summarise what changed and how to test it; don't declare work done or move on to the next task.
